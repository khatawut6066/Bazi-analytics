Voice QA

ชุดทดสอบเสียงอ่านและ cache แบบไม่เสียค่า API

หน้านี้ใช้ตรวจทุกเคสที่เว็บสามารถแสดงได้: อ่านสดจาก browser, เล่นบทอ่านล่าสุด, cache ไฟล์ static, และ fallback เมื่อไม่มีเสียง

กลับหน้าเว็บ
1. ตรวจ Web Speech API

ดูว่า browser เครื่องนี้อ่านเสียงเองได้ไหม

2. ทดสอบอ่านสด

ให้ browser อ่านประโยคไทยสั้น ๆ จากการกดของผู้ใช้

3. เก็บบทอ่านล่าสุด

จำลองการเก็บข้อความในเครื่องผู้ใช้สำหรับเปิดซ้ำ

4. เปิดบทอ่านล่าสุด

ดึงข้อความที่เก็บไว้มาอ่านซ้ำ ถ้า browser รองรับ

5. ตรวจ manifest เสียงสำรอง

ดูรายการไฟล์เสียง static ที่พร้อม cache เมื่อมีไฟล์จริง

6. ทดสอบ cache ไฟล์เสียง

ลอง cache ไฟล์ที่มีอยู่จริงเท่านั้น ถ้ายังไม่มีไฟล์จะแจ้ง missing
